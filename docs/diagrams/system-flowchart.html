DECISION & EXECUTION PIPELINE

履約里程碑推算與預警派發 — 系統流程圖

端對端業務流程：涵蓋開工日配置、Gemini 3.7 五維度合約萃取、DGPA 避假推算、定時排程稽核與多通道發布。

STAGE 1 · AI PARSING

合約五維度結構化解析

  • 多模態輸入：支援純文字、PDF、Word (.docx) 及 CSV。
  • 五大維度抽取：里程碑名稱、D+N 天數、交付產出物、逾期違約罰則與合約條文索引。
  • 離線啟發式 Fallback：未填 API Key 或斷網時自動啟用正規表達式引擎。

STAGE 2 · CALENDAR LOGIC

DGPA 國定假日與補班推算

  • 精確避假：履約死線遇例假日或國定假日，自動推延至次一有效工作日。
  • 補班日判定：精確識別行政院公告之週六彈性補班日，不誤延死線。
  • 提前預警計算：依專案配置之提前通知天數，回推預警啟動日。

STAGE 3 · DISPATCH & AUDIT

定時稽核與多通道發布

  • 每日 09:00 AM 常駐掃描：自動比對多重預警門檻 (7, 3, 1 天與當天)。
  • 正統 Outlook 預約：生成 iCalendar v2.0 .ics 檔與 Outlook Web 深層連結。
  • Teams Webhook 推送：即時傳送 Adaptive 卡片與記錄通知 Log。
